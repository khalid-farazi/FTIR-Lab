# Quran splash-screen sources

This application displays one randomly selected ayah at startup. Content is stored offline and is not modified by the application.

- Arabic: Uthmani text supplied with QuranEnc API records.
- English: English Translation — Rowwad Translation Center (`english_rwwad`, version 1.0.19).
- Bengali: Bengali Translation — Abu Bakr Zakaria (`bengali_zakaria`; use the current QuranEnc release).
- Source: https://quranenc.com/
- API: https://quranenc.com/en/home/api/

QuranEnc permits translation content to be downloaded and republished provided it is not modified, the publisher/source and version are identified, transcript information is retained, notes are reported to QuranEnc, and releases are kept updated. See the Terms and Policies on the API page.
